# EyeGuard

EyeGuard is a privacy-first iPhone app for encouraging comfortable screen habits.

## Current stage

This folder contains the first SwiftUI screen. It is intentionally UI-only:

- no camera permission yet
- no TrueDepth code yet
- no background monitoring yet
- no medical or vision-health claims

## Running it later on a Mac

1. Open Xcode and choose **Create a new Xcode project**.
2. Choose **iOS > App**.
3. Set the product name to `EyeGuard`.
4. Choose **SwiftUI** for Interface and **Swift** for Language.
5. Replace the generated `EyeGuardApp.swift` and `ContentView.swift` with the files in this folder.
6. Run the project in an iPhone Simulator.

The TrueDepth prototype will be added only after this basic screen builds successfully.
