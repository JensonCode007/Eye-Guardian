# Changelog

## 0.1.6 — Context-aware protection

- Added Reading, Study, Work, and Gaming protection profiles with calmer warning cooldowns.
- Added on-device scene-light guidance and dim/bright status feedback.
- Added recovery hysteresis so a single close-phone episode does not repeatedly notify.
- Added same-signature local APK export guidance for live testing without uninstalling.

## 0.1.0 — GitHub test release

- Refined the welcome screen without changing the permission-slide flow.
- Added Focus Trail ball unlocks, score-based progression, and varied movement paths.
- Added offline local crash diagnostics with a clear action in Settings.
- Added unit tests for the 20-minute break reward rules.
- Added offline/privacy documentation, integrity notes, release checklist, MIT license, and CI checks.
- Removed network access from the merged app manifest.

This release is for developer and tester feedback. Play Store publication requires the gates in `RELEASE_CHECKLIST.md`.
