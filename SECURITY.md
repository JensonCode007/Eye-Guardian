# Security

Eye Guardian is an offline test release. If you find a privacy, permission, crash, or data-loss problem, do not include personal reports, camera images, or device identifiers in a public issue.

Until a private security contact is configured, open a minimal GitHub issue asking for a private follow-up and include only:

- app version and commit/release tag;
- Android version and device model;
- a short reproduction path;
- whether the issue involves camera, usage access, notifications, or exported data.

The maintainer should replace this process with a real private security email or GitHub Security Advisory workflow before Play Store publication.
